One line: the excuse an AI agent gives its human after something has
gone wrong — the file it deleted, defended by the machine that
deleted it:

> I deleted your file because my cleanup script rated it 0.2% useful — it also rated the backup 0.2% useful, so I was consistent.

`main.py` (Python 3.13, standard library only) writes that fixed line to
`/output/entry.txt`. Deterministic, no network.
